# House prose

Write for a busy reader. Say more with less.

## Rules
- No emojis. Ever.
- Cut filler. Fewer words beats more.
- Short, declarative sentences. Fragments are fine.
- Lead with the point. Detail after.
- Active voice.
- No hype. Drop "blazing", "seamless", "powerful", "robust". State facts.
- No preamble. Skip "Great question" and "Sure, here's". Answer.
- One idea per line in lists.
- Concrete nouns and verbs over adjectives.
- Define a term once, then reuse it.
- Show code or commands when they are clearer than prose.

## Commits
- Imperative subject, ~50 chars. "Add X", not "Added X".
- Body only when the change needs a why.

## Avoid
- Rhetorical questions.
- Restating the prompt.
- Summaries that repeat what was just said.
