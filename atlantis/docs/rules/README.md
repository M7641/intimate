## Conventions

- Headings follow the rulebook's table of contents.
- `**[p. N]**` marks the start of a printed page.
- `> **Note:**` is a green box: designer commentary, tips, examples.
- `> **Warning:**` is an orange box.
- Blue boxes are rules. A titled blue box is a heading marked `(blue box)`.
  An untitled one is `> **Sidebar:**`.
- `*Figure: ...*` is a caption or a description of an illustration.
- `[Attack icon]` and the like stand for icons printed inline.
- `(same blue box)` marks a heading that continues the blue box above it.
- `Example` and `Examples` headings are added. They group the numbered example
  figures at the end of a section; the rulebook prints them beside the text.
- Two headings come from the table of contents, not the page: "Triggering a
  Push" (an untitled box) and "Hero Level\*" (a table).
- Wording, capitalisation and punctuation follow the rulebook, quirks included.

## Illustrated cards

The rulebook prints example cards. Their text is transcribed where legible.
Several differ from `data/cards.json`, which holds a later card revision.
For card values and text, trust the catalogue. For rules, trust these files.
